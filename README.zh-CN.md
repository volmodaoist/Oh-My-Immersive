# Oh-My-Immersive

由 [volmodaoist](https://github.com/volmodaoist) 维护，基于 iBlinkQ 的 [Immersive Folder](https://github.com/iBlinkQ/immersive-folder) 0.6.0。保留原版权和 MIT 声明，本 fork 增加任意文件排序和浏览器临时书写。

[English](README.md) · 简体中文 · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

一个 Obsidian 插件。你在某个文件夹里工作时，可以一键只专注于这个文件夹中的笔记，
其他内容被暂时遮住。你也可以直接拖动文件和文件夹调整顺序，不必再靠数字前缀
这样的命名去凑出想要的次序。

![文件列表中 Clippings 文件夹保持可读，其余每一行都变成骨架条](docs/screenshot.png)

聚焦哪个文件夹是根据你当前打开的文件自动判断的 —— 不用手动选。

## 为什么要有它

- **专注。** 两千篇笔记的库，不再和你手头真正在处理的那十几篇抢注意力。
- **会上投屏。** 开会讲某个项目时把屏幕投出去，满屋子人看到的只有你要讲的那个
  文件夹，而不是隔壁项目、另一个客户、以及你自己私下记的那些东西的名字。
- **录屏分享。** 只展示视频要讲的那个文件夹，侧边栏其余部分保持不可读，不用为了
  录一段视频先去重新整理你的库。

## 怎么用

- **文件列表顶部的按钮**，点一下开关。遮挡开启时它会染上你的主题强调色，一眼
  就能看出当前状态。
- **命令面板里的 `Oh-My-Immersive: Toggle immersive folder`**，同样的作用，可以
  绑快捷键 —— 如果你经常在录屏前后开关，值得绑一个。

开关状态会在重启后保留。

### 调整文件与文件夹顺序

点击文件列表顶部的上下箭头按钮，任意类型的文件和文件夹都会长出手柄，
可以拖动调整顺序。改动随手保存，再点一次按钮或者按 Esc 退出。
也可以右键任意文件夹，选择**重新排序**进入同一个模式。

![拖动文件夹可以改变它在同级文件夹中的位置](docs/arrange.gif)

文件夹始终排在文件前面。同一目录下，文件夹只能在文件夹之间调整，文件只能在文件
之间调整，不同类型的文件也可以互相排序；不能跨目录排序，也不能把文件拖到文件夹区域。

拖动后，该目录保存文件和文件夹两组的当前顺序，切换 Obsidian 排序菜单或重启后仍然
保留。其他目录继续跟随 Obsidian 排序菜单。新建或移入的内容放在各自分组末尾，
它们之间按 Obsidian 的顺序排列，直到你再次手动调整。

要恢复某个目录的默认排序，先退出调整模式，再右键文件或文件夹，选择菜单中标明
目标目录的**恢复默认排序**。右键文件夹时，可能同时看到恢复它内部和它所在目录的
入口，`/` 表示库的根目录。恢复只清除该目录的排序记录，子目录保留各自的顺序。
设置页也提供**恢复所有目录的默认排序**，可以一次清除全部手动排序记录。

升级到这个版本时，原有的文件夹排序记录会清空一次。

退出调整模式后，Obsidian 原生拖拽照常可用。插件只记录显示顺序，不重命名、不移动文件。

### 远程书写（桌面端原型）

笔记区域右上角新增铅笔按钮，点击启动局域网书写服务并显示连接地址，再点一次停止。
也可以从命令面板打开「远程书写连接」，或在插件设置中点击「远程书写」。关闭连接
窗口后服务继续运行，连接地址可以随时从命令或设置重新打开。

另一台设备连接同一局域网，在浏览器中打开复制的地址，即可看到本机 Obsidian 的当前
窗口作为底图，并在上面书写。没有 iPad 时，可以在另一个浏览器中按住鼠标左键拖动测试。
Apple Pencil 使用压感，鼠标使用固定粗细；手指和手掌不会落墨，也不会结束当前笔迹。
支持笔、荧光笔、整条笔迹橡皮、撤销和清屏。开启服务时，笔记标题栏也会出现橡皮图标的
**清屏**按钮；网页端也有**清屏**。从任意一端清屏，两端都会同步清除笔迹。
书写区域关闭长按选择、图片拖拽和浏览器菜单，避免 Pencil 停留时弹出「拷贝」等操作。

书写中约每 20ms 批量回传采样点，本机透明层持续显示笔迹；抬笔后完成一条笔迹。
取消事件会丢弃未完成的笔迹。底图定时刷新，笔迹使用统一坐标，保持两端的位置对应。

第一版笔迹固定在窗口画面上，滚动或切换笔记不会跟随内容移动。笔迹仅保存在当前
服务的内存中，不写文件；停止服务或关闭 Obsidian 后清空，再次启动从空白笔迹开始。
同一服务运行期间刷新浏览器会恢复内存中的笔迹。原型之前生成的 `ink.json` 会在启动时清理。

连接弹窗使用主题的原生圆角和按钮组件。点击时按钮短暂高亮，文字和图标保持不变；
停止后弹窗显示「已停止」状态，操作失败会在弹窗内显示原因。标题栏按钮也使用相同的
点击高亮反馈。

设置中的服务端口默认为 `8674`，可设为 `1024` 到 `65535` 之间的整数，修改在下次
启动服务时生效；笔记标题栏中的远程书写按钮可以单独隐藏。此服务从桌面 Obsidian 启动，浏览器客户端
可以在 iPad 或电脑使用。本机笔迹使用透明子窗口，录屏时应选择包含该层的屏幕画面。

### 设置项

**语言（Language）** —— 界面默认跟随 Obsidian 自己的语言设置。插件自带英文和
简体中文，也可以在这里手动指定。切换即时生效，命令名也会跟着变。

**工具栏按钮（Toolbar buttons）** —— 本插件的两个按钮里，哪些留在文件列表顶部。
两个按钮各自都能看出对应模式开没开，所以默认都摆在明面上；如果你只用其中一个
功能，可以把另一个藏起来。藏起来的那个，命令面板里照样能用；藏了东西之后，设置页
会多出一行，点一下直接带你去快捷键页面。

**让当前文件始终可见（Keep the active file in view）** —— 每次切换笔记时，滚动
文件列表到那篇笔记，并展开必要的层级把它露出来。没有这个的话，切到一篇所在文件夹
恰好在视野之外的笔记，你会看到满屏骨架条、别的什么都没有。默认开启。

**收起其他所有文件夹（Collapse every other folder）** —— 每次切换时，把除当前
文件夹之外的所有文件夹都收起来。需要滚动的内容更少，也让骨架条不再暴露其他文件夹
里装了多少东西。退出沉浸模式时，原先展开的文件夹会照原样恢复。默认开启。
进入沉浸模式后才展开的目录，也会在退出时重新收起。

**显示当前文件夹里的所有层级（Keep everything inside this folder readable）** ——
开启沉浸模式后，当前文件夹里不管展开到第几层，文件名和文件夹名都照常显示。关掉
这一项，就只显示直接放在它里面的文件和文件夹，再往里展开一层又是骨架条。当前
文件夹以外不受影响，旁边的文件夹一律遮住，上层文件夹看下一项。默认开启。

**显示上层文件夹（Keep the folders above this one readable）** —— 开启沉浸模式后，
从当前文件夹往上一直到库的根目录，沿途每一层文件夹的名字都照常显示，看得出自己
在树的哪个位置。只放开这条路径本身，路径旁边的文件夹照样遮住。默认关闭，因为
顶层文件夹的名字往往最能透露你在做什么。

## 它做不到什么

**这是视觉遮挡，不是加密。** 那些名字仍然在页面里，任何人打开开发者工具都能读到。
它是为镜头、投影仪和你旁边那个人准备的，不是为了防住一个已经能操作你电脑的人。

遮挡也只作用于文件列表：标签页标题、笔记自己的面包屑、搜索结果和快速切换器都不受
影响，想按名字搜索，先把遮挡关掉。另外，如果你关掉「收起其他所有文件夹」，骨架条
仍然会露出每个文件夹里有多少个文件、树有多深。

## 安装

当前可通过源码或 [GitHub Releases](https://github.com/volmodaoist/Oh-My-Immersive/releases) 手动安装。
社区目录上架状态会在提交并通过审核后更新。

需要 **桌面版 Obsidian 1.15.1 或更高版本**。iPad 和电脑浏览器可以连接远程书写；
插件本身不在移动版 Obsidian 中安装。

### 从源码安装

先安装 Node.js（建议 LTS 版本）、npm 和 GNU Make，并在 Obsidian 中打开过目标库，
确保该目录已经有 `.obsidian`。然后执行：

```bash
git clone https://github.com/volmodaoist/Oh-My-Immersive.git
cd Oh-My-Immersive
make install vault="/你的 Obsidian 库路径"
```

路径包含空格时需加引号，中文路径也可使用。命令会安装缺少的开发依赖、构建插件，
并将 `main.js`、`manifest.json`、`styles.css` 复制到
`<vault>/.obsidian/plugins/oh-my-immersive/`。重复安装会保留已有 `data.json` 配置。
目标库会在构建前校验，路径写错时不会创建一个空库。

安装后，在 设置 → 第三方插件 中启用 **Oh-My-Immersive**；更新后重新加载插件或
重启 Obsidian。若同一库已启用原插件 Immersive Folder，请先停用它，避免两份插件
同时接管文件列表排序。

### 从发行版手动安装

下载同一个 Release 中的 `main.js`、`manifest.json`、`styles.css`，放入
`你的库/.obsidian/plugins/oh-my-immersive/`，然后启用插件。
`main.js` 是构建产物，在 Release 中提供，不保存在源码仓库里。

问题和建议可提交到 [Issues](https://github.com/volmodaoist/Oh-My-Immersive/issues)。

## 开发

```bash
npm install
npm run dev     # 监听构建
npm run build   # 类型检查并构建 main.js
npm run lint    # 社区插件审核所用的那套规则
make install vault="/path/to/vault"  # build and install into a vault
```

`npm run lint` 必须在仓库根目录跑：规则会从工作目录读 `manifest.json`。

## 发布新版本

发布到 GitHub Release 可使用快速命令，需配置 Git 身份、origin 的推送权限和 Python 3。
无需本机登录 GitHub CLI；附件由已启用的 GitHub Actions 发布流程上传。

1. 在 `CHANGELOG.md` 的 `## Unreleased` 下写好本次变更，并提交代码和文档，保持工作区干净。
2. 在 `main` 分支预览：

   ```bash
   make release-dry-run version=1.0.1
   ```

3. 确认目标版本和仓库后执行：

   ```bash
   make release version=1.0.1
   ```

命令会同步 `package.json`、`package-lock.json`、`manifest.json`、`versions.json`，
将 Unreleased 说明移入新版本，运行测试、构建和 lint，再通过 `check-commit.py`
创建版本提交与同名标签，原子推送 `main` 和标签。

随后查看仓库 [Actions](https://github.com/volmodaoist/Oh-My-Immersive/actions)。
流程成功后，[Releases](https://github.com/volmodaoist/Oh-My-Immersive/releases) 中会出现
`main.js`、`manifest.json` 和 `styles.css`，发行说明来自新版本的 CHANGELOG 段落。

版本必须是递增的 `x.y.z`，标签不加 `v`。预览不会改文件、提交、标签或远端。
校验失败会撤回脚本自己的版本文件修改；若提交已创建而推送失败，脚本会给出检查和重试命令。
这些命令只发布 GitHub 发行版，社区目录提交仍是独立步骤。
