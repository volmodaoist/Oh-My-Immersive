# 远程书写模块

桌面 Obsidian 启动局域网服务，浏览器即时绘制笔迹，再通过 POST 上传操作。
服务端维护唯一的内存状态，通过 SSE 将快照和增量操作广播给各个页面。
笔迹固定在窗口坐标中，不跟随笔记内容滚动，也不写入文件。

## 本机连接面板

标题栏按钮悬停时打开临时面板，点击可固定或收起。面板中的操作和键盘焦点会固定
面板，防止启动或复制时随指针离开而关闭；点击外部或按 Esc 收起。原生 popover
顶层避开标题栏的裁剪，监听和延时在关闭时统一释放。关闭面板不停止服务。

打开面板与 `startInk()` 分开，只有显式点击启动才创建局域网服务。地址输入框默认
使用 password 类型遮挡，显隐按钮只改变视觉显示；复制始终使用完整连接地址。
关闭再打开面板或更换服务连接码都会重新遮挡地址。状态来自宿主刷新，不轮询。

停服先关闭监听，再主动断开包含活动请求在内的 HTTP 连接。截图未返回、客户端
未完成上传或仍保持 SSE 连接时，也不能拖住停止。停服后迟到的截图不写入已关闭响应。

## 远程上下滚动

网页工具栏的上移、下移按钮每次滚动半个笔记可视区域，也支持底图上的鼠标滚轮。
指令按可视高度比例归一化，50ms 内的滚轮输入合并，每次最多回传一屏，独立于笔迹队列。
手指和手掌在书写区仍不触发操作；iPad 通过工具栏按钮控制上下滚动。

`GET /api/scroll` 返回当前可用目标的临时标识，`POST /api/scroll` 接收 `{ target, amount }`。
这两个入口使用同一连接码和来源检查，滚动请求体最多 1KB；切换笔记、模式或分屏后，
旧标识失效。任一客户端仍有未完成笔迹时，服务端拒绝滚动。

仅操作主窗口当前选中的 Markdown 笔记。编辑模式使用公开的编辑器滚动 API，阅读
模式操作对应容器，保留水平位置、编辑光标和焦点。滚动不移动或清除已有笔迹；
底图通过现有截图刷新展示结果。停服或取消后的迟到请求不再执行操作。

## 操作与同步约定

- `Begin` 立即创建一条包含首个点的未完成笔迹。
- `Append` 在书写中分批上传；`offset` 是本批首点在完整笔迹中的下标。
- `End` 在抬笔后标记完成；`Cancel` 直接丢弃系统中断的笔迹。
- `Delete` 擦除指定笔迹；`Clear` 清空所有内存笔迹。

这些枚举保留原协议的 `begin`、`append`、`end`、`cancel`、`delete`、`clear` 值。
`InkOp` 使用枚举成员作为判别字段，并保留不同操作的载荷类型。

客户端先本地绘制以保证跟手，操作通过串行队列发送，避免网络乱序。
服务端只有实际改变状态时才增加 `revision`。客户端发现重复事件会忽略，
发现序号缺口会重新获取快照。自己的 SSE 回显不能覆盖尚未上传的本地采样点。

## 输入和绘制边界

- Pencil 和鼠标左键可以书写；手指与手掌不产生笔迹。
- Safari 的触摸默认行为与 Pointer Events 分开处理，取消默认长按动作时不阻断笔迹事件。
- 坐标存为 `[x, y, pressure]`，三项都在 0～1 范围内；不同尺寸画面按比例绘制。
- 已完成笔迹与活动笔迹分别合成；荧光笔在图层合成时统一应用透明度。
- 底图先完成解码再绘制，旧帧在加载和失败期间继续显示，位图资源在复制像素后释放。

## 格式与验证

在仓库根目录执行：

```bash
npm run format:ink
npm run lint
npm test
```

`format:ink` 统一此目录的格式，`lint` 同时检查格式与代码规则。
修改枚举时保留已有序列化值；调整网络处理时保留输入验证、采样上限和序号检查。
