# Oh-My-Immersive

[volmodaoist](https://github.com/volmodaoist) が保守しています。iBlinkQ の [Immersive Folder](https://github.com/iBlinkQ/immersive-folder) 0.6.0 を基にしており、元の著作権表示と MIT ライセンスを保持します。

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · 日本語 · [한국어](README.ko.md)

Obsidian のプラグインです。あるフォルダーで作業しているあいだ、ワンクリックで
ファイルエクスプローラーをそのフォルダーのノートだけに絞り込み、それ以外は
いったん覆い隠します。ファイルとフォルダーはドラッグで好きな順に並べ替えられるので、
順番をそろえるために `01_Inbox`、`02_Projects` のような名前を付ける必要も
なくなります。

![Clippings フォルダーだけが読め、ほかの行はすべてスケルトンバーになったファイルエクスプローラー](docs/screenshot.png)

どのフォルダーに没入するかは、開いているファイルから自動的に決まります。選ぶ操作は
ありません。

## なぜ必要か

- **集中。** 2000 件のノートを抱えた保管庫が、いま実際に手を動かしている十数件と
  注意を奪い合わなくなります。
- **会議での投影。** プロジェクターに映してひとつのプロジェクトを説明するとき、
  部屋の全員が読むのはそのプロジェクトだけです。隣のプロジェクトや別の顧客、
  自分用に置いてあるものの名前が目に入ることはありません。
- **画面録画。** 動画で扱うフォルダーだけを見せ、サイドバーの残りは読めないままに
  できます。撮る前に保管庫を整理し直す必要はありません。

## 使い方

- **ファイルエクスプローラー上部のボタン**で切り替えます。覆いが出ているあいだは
  アクセントカラーを帯びるので、状態がひと目で分かります。
- コマンドパレットの **`Oh-My-Immersive: Toggle immersive folder`** も同じ働きを
  します。ホットキーを割り当てられるので、録画のたびに切り替えるなら便利です。

状態は再起動をまたいで保持されます。

### ファイルとフォルダーの順序を変える

ファイルエクスプローラー上部の上下矢印ボタンを押すと、すべての種類のファイルと
フォルダーにハンドルが現れ、ドラッグで並べ替えられます。変更はその都度保存され、
もう一度ボタンを押すか Esc を押すとモードを終了します。
フォルダーを右クリックして **Reorder** を選んでも、同じモードに入れます。

![フォルダーをドラッグして同じ階層の中での位置を変える](docs/arrange.gif)

フォルダーは常にファイルより前に並びます。同じディレクトリ内で、フォルダー同士、
ファイル同士の順序を変えられます。異なる種類のファイルも並べ替えられますが、
別のディレクトリやファイルとフォルダーのグループをまたいで移動することはできません。

ドラッグすると、そのディレクトリの両グループの順序が保存され、Obsidian の並べ替え
メニューを変更したり再起動したりしても保持されます。ほかのディレクトリは Obsidian
の並べ替えに従います。新規作成・移入した項目は各グループの末尾に Obsidian の順序で
並び、次に手動で並べ替えるまでその位置を保ちます。

既定の順序に戻すには、モードを終了してファイルまたはフォルダーを右クリックし、
対象ディレクトリが表示された **Restore default order** を選びます。フォルダーの
メニューには内部と親ディレクトリの両方が表示される場合があり、`/` は保管庫のルート
を表します。子ディレクトリの順序は保持されます。設定の
**Restore default order everywhere** では、すべての手動並べ替えを解除できます。

このバージョンへの更新時、従来のフォルダーのみの並べ替え記録は一度消去されます。

モードを終了すると Obsidian 本来のドラッグが使えます。プラグインは表示順だけを
記録し、ファイルの名前や保存場所を変えません。

### リモート手書き（デスクトップ版の試作機能）

ノート右上の鉛筆ボタンで LAN 手書きサービスを開始し、もう一度押すと停止します。
**Remote ink connection** コマンドまたは設定から接続先を再表示できます。同じ LAN の
ブラウザーでコピーした URL を開き、現在の Obsidian 画面の上に書き込めます。
マウスの左ボタンを押したままドラッグしても試せます。Pencil は筆圧を使用し、マウスは
一定の太さです。指や手のひらでは描画しません。ペン、蛍光ペン、ストローク消去、
取り消し、全消去に対応し、描画中から送信します。ブラウザーとデスクトップの両方に消去ボタンがあります。

筆跡は画面に固定され、ノートのスクロールや切り替えには追従しません。筆跡はサービスのメモリーだけに保持され、
サービス停止や Obsidian 終了時に消去されます。ファイルには保存しません。ポートの既定値は `8674` で、設定変更は次回起動時に反映されます。
ホストはデスクトップ版 Obsidian が必要です。透明な子ウィンドウを使用するため、
録画ではそのレイヤーを含む画面全体をキャプチャしてください。

### 設定

**Language（言語）** —— インターフェースは Obsidian 自体の言語設定に従います。
プラグインに同梱されているのは英語と简体中文で、ここで選べばその判定を上書き
できます。コマンド名も含め、その場で切り替わります。

**Toolbar buttons（ツールバーボタン）** —— このプラグインの 2 つのボタンのうち、
どれをファイルエクスプローラーの上部に置くか。どちらもモードのオン・オフが見える
スイッチなので、既定では両方とも見える場所にあります。片方の機能しか使わないなら
もう一方は隠せます。隠したものもコマンドパレットからは使え、何かを隠すと設定
ページからホットキー設定へ直接移動できる行が現れます。

**Keep the active file in view（アクティブなファイルを表示範囲に保つ）** ——
ノートを切り替えるたびにエクスプローラーをそのノートまでスクロールし、必要な階層を
展開して見えるようにします。これがないと、フォルダーが表示範囲外にあるノートへ
切り替えたとき、画面にはバーだけが残ります。既定でオンです。

**Collapse every other folder（ほかのフォルダーをすべて折りたたむ）** ——
切り替えのたびに、いるフォルダー以外をすべて折りたたみます。スクロールする量が
減り、ほかのフォルダーが何件抱えているかをバーが漏らすこともなくなります。開いて
いたものは没入モードを抜けるときに元に戻ります。既定でオンです。

**Keep everything inside this folder readable（このフォルダーの中身は読めるままに
する）** —— 覆いがもともと見逃すのは、いるフォルダーと、その直下に入っているもの
だけです。オンにすると、その先も一緒に見逃します。中のサブフォルダーを開けば、
その中身はバーにならずそのまま読めます。いるフォルダーの横に並ぶフォルダーは、
どちらの場合も覆われたままです。上のフォルダーは次の項目で決まります。既定でオン
です。

**Keep the folders above this one readable（上のフォルダーを読めるままにする）**
—— いるフォルダーから保管庫のルートまで、たどる途中のフォルダーがすべて名前を
残すので、ツリーのどこにいるかがわかります。見逃すのはこの道筋そのものだけで、
その横にあるフォルダーは覆われたままです。最上位のフォルダー名には何の作業をして
いるかがいちばん表れやすいため、既定でオフです。

## できないこと

**これは視覚的な覆いであって、暗号化ではありません。** 名前はページの中に残って
いるので、開発者ツールを開ける人には読めます。カメラやプロジェクター、隣の席の人を
想定したものであって、すでにあなたのマシンを操作できる相手を想定したものでは
ありません。

覆いがかかるのはファイルエクスプローラーだけです。タブのタイトル、ノート自身の
パンくず、検索結果、クイックスイッチャーはそのままなので、名前で検索したいときは
覆いを外してください。また **Collapse every other folder** をオフにすると、各
フォルダーが何件抱えているか、ツリーがどれだけ深いかはバーから伝わります。

## インストール

現在はソースから、または [GitHub Releases](https://github.com/volmodaoist/Oh-My-Immersive/releases) から手動で
インストールできます。コミュニティ掲載状況は審査後に更新します。
**デスクトップ版 Obsidian 1.15.1 以上**が必要です。iPad はブラウザーで接続できます。

Node.js（LTS 推奨）、npm、GNU Make を用意し、対象の保管庫を一度 Obsidian で開いてから実行します：

```bash
git clone https://github.com/volmodaoist/Oh-My-Immersive.git
cd Oh-My-Immersive
make install vault="/path/to/your Obsidian vault"
```

スペースを含むパスは引用符で囲んでください。依存関係を用意してビルドし、
`<vault>/.obsidian/plugins/oh-my-immersive/` にファイルをコピーします。
既存の `data.json` は保持します。設定で **Oh-My-Immersive** を有効にしてください。
元の Immersive Folder は先に無効にし、更新時はプラグインを再読み込みします。

同じ Release の `main.js`、`manifest.json`、`styles.css` を手動配置することもできます。
質問は [Issues](https://github.com/volmodaoist/Oh-My-Immersive/issues) へお願いします。

## 開発

```bash
npm install
npm run dev     # ウォッチビルド
npm run build   # 型チェックして main.js をビルド
npm run lint    # コミュニティプラグイン審査が走らせるルール
make install vault="/path/to/vault"  # build and install into a vault
```

`npm run lint` はリポジトリのルートで実行する必要があります。ルールが作業ディレクトリ
から `manifest.json` を読むためです。
